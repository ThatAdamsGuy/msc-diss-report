# Thesis Statement
Research Question:
Can a deterministic engineering model predict Formula One undercut effectiveness using measurable race parameters with sufficient accuracy to support strategic decision making?

Hypothesis:
A simplified deterministic model incorporating tyre degradation, compound performance and warm-up effects can provide practically useful undercut predictions without modelling the full race.

Contribution:
- Engineering model for undercut prediction
- Implemented analysis tool
- Validation against historic races
- Evaluation of assumptions and sensitivity
